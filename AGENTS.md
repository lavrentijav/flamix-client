# flamix-client

Специфика проекта. Общие правила среды — в `/srv/dev/AGENTS.md` (обязательны).

## Правила
- Разработка тут (`~/projects/flamix-client`), релиз — `release-sync flamix-client` → запуск из `~/release/flamix-client`.
- Git: локальные коммиты с осмысленными сообщениями (видно через `git log`/`git diff`).
- Долговременная документация — `~/doc` (по git). Временное/бэкапы — `~/backup`.
- Доступ к серверам флота — под аккаунтом `agent` (ключ ~/.ssh/id_ed25519_agent).
