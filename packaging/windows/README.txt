Flamix — cross-platform VPN client (Xray / sing-box)
=====================================================

Portable build: flamix.exe uses the cores bundled in the "cores" folder
(xray.exe, sing-box.exe, geoip.dat, geosite.dat).

URL scheme: flamix:// (subscription / server links) is registered by the
installer and by the app on first run.

Uninstall: use "Apps & features" / the Start menu uninstall shortcut.
User data lives in %APPDATA%\flamix.
